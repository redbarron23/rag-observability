# Payments API Service Level Objectives

Fictional document: Northwind Systems, its teams and services are invented.

## Availability target

The Payments API availability target is 99.9% of successful requests, measured over a rolling 30-day window. That allows an error budget of about 43 minutes of full unavailability per 30 days.

## Latency target

95% of Payments API requests must complete within 300 ms over the same 30-day window.
