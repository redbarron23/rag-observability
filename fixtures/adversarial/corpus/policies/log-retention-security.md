# Security Logging Standard

Fictional document: Northwind Systems, its teams and services are invented.

Owner: Information Security. Status: in force. Effective from 1 March 2026.

## Retention target

Production application logs must be retained for 400 days so that security investigations can reach back more than a year. Deleting production application logs before 400 days is not permitted.

## Scope

This standard applies to application logs from every production service, wherever they are stored.
